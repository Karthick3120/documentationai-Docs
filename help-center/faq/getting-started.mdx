## Overview

To start using Karthick K, follow these steps:

1. Sign up at `https://karthick.dev/register`
2. Create your first workspace
3. Add team members or invite collaborators
4. Start organizing your documentation

## Next Steps

Visit your dashboard to access and edit all your docs in one place. Every change is autosaved.
